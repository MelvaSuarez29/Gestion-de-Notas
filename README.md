# Gestión de Notas Académicas

## Descripción del Proyecto
**Gestión de Notas Académicas** es una aplicación de escritorio desarrollada en **C++** utilizando el framework **Qt Creator**.  
El sistema permite la administración, registro y consulta de calificaciones académicas, facilitando la gestión educativa de manera digital y eficiente.

Este proyecto está orientado a la carrera de **Desarrollo de Software** de la **Escuela Politécnica Nacional (EPN)**.

---

## Tecnologías Utilizadas
- Lenguaje de programación: **C++**
- Framework: **Qt (Qt Creator)**
- Tipo de aplicación: **Aplicación de escritorio**

## Motivación del Proyecto

El sistema fue desarrollado con el objetivo de automatizar y digitalizar la gestión académica, respondiendo a una necesidad real dentro del entorno universitario.  
Se seleccionó específicamente la carrera de **Desarrollo de Software de la EPN** por los siguientes motivos:


1. **Necesidad real:**  
   Muchas instituciones educativas aún dependen de procesos manuales para la gestión de notas, lo que genera errores y retrasos en los procesos académicos.

2. **Complejidad adecuada:**  
   El sistema involucra múltiples entidades como estudiantes, materias y calificaciones, permitiendo aplicar conceptos fundamentales de programación y diseño de software.

3. **Aplicación práctica:**  
   Resuelve un problema cotidiano dentro de la educación superior, facilitando el acceso, control y organización de la información académica.

4. **Escalabilidad:**  
   El sistema puede adaptarse y extenderse fácilmente a otras carreras o instituciones educativas.

---

## Elementos del código QT y Cpp
1) Sistema de login con autenticación
2) CRUD completo de estudiantes
3) Registro y gestión de notas académica
4) Cálculo automático de promedios ponderados
5) Validación de datos de entrada
6) Exportación de reportes en formato TXT
7) Interfaz gráfica intuitiva con Qt
8) Persistencia de datos en archivos planos
---

## Limitaciones del aplicativo 
No incluye gestión de docentes,
No maneja horarios de clases,
No genera facturación,
No tiene módulo de inscripciones en línea.
